# Internationalization & Multi-Locale Routing (`NuStreamDocs.I18n`)

`NuStreamDocs.I18n` turns a single documentation build into a multi-language site in pure UTF-8:

- **Directory & Filename-Suffix Routing**: Supports both directory-prefixed (`en/guide/setup.md`, `fr/guide/setup.md`) and suffix-named (`guide/setup.fr.md`) translations, pairing matching logical pages automatically.
- **Missing-Translation Fallbacks**: Synthesizes fallback pages from `DefaultLocale` for any untranslated locale so cross-locale links never 404, with an optional `UntranslatedNotice` banner preserved cleanly after YAML frontmatter.
- **HTML `lang` & `<head>` `hreflang` Links**: Rewrites `<html lang="...">` per page and injects `<link rel="alternate" hreflang="...">` plus `hreflang="x-default"` into `<head>`.
- **Accessible Language Switcher**: Injects `<nav class="nd-lang-switcher" aria-label="Language">` with `aria-current="page"` and ships `/assets/stylesheets/i18n.css`.
- **Localized `sitemap.xml` Enrichment**: Automatically adds `xmlns:xhtml="http://www.w3.org/1999/xhtml"` and `<xhtml:link rel="alternate" hreflang="..."/>` entries to `sitemap.xml` when `NuStreamDocs.Sitemap` is enabled.

## Installation

```bash
dotnet add package NuStreamDocs.I18n
```

## Quick Start

```csharp
using NuStreamDocs.Building;
using NuStreamDocs.I18n;
using NuStreamDocs.Sitemap;
using NuStreamDocs.Theme.Material3;

await new DocBuilder()
    .WithInput("docs")
    .WithOutput("site")
    .WithSiteName("My Docs"u8)
    .WithSiteUrl("https://docs.example.com"u8)
    .UseDirectoryUrls()
    .UseMaterial3Theme()
    .UseSitemap()
    .UseI18n(opts => opts
        .WithDefaultLocale("en")
        .AddLocale("en", "English"u8)
        .AddLocale("fr", "Français"u8)
        .AddLocale("ja", "日本語"u8)
        .WithUntranslatedNotice("> **Note:** This page is shown in English while translation is in progress."u8))
    .BuildAsync();
```

## Authoring Layouts

### 1. Directory-Prefixed Locales

```text
docs/
  en/
    index.md
    guide/setup.md
  fr/
    index.md
    guide/setup.md
  ja/
    index.md          # ja/guide/setup.md is synthesized automatically from en/guide/setup.md!
```

### 2. Filename-Suffixed Locales

```text
docs/
  index.md            # DefaultLocale ("en")
  index.fr.md         # "fr"
  index.ja.md         # "ja"
```

## Generated Markup

For `/fr/guide/setup/`, `NuStreamDocs.I18n` sets `<html lang="fr">`, injects into `<head>`:

```html
<link rel="alternate" hreflang="en" href="https://docs.example.com/en/guide/setup/">
<link rel="alternate" hreflang="fr" href="https://docs.example.com/fr/guide/setup/">
<link rel="alternate" hreflang="ja" href="https://docs.example.com/ja/guide/setup/">
<link rel="alternate" hreflang="x-default" href="https://docs.example.com/en/guide/setup/">
```

and renders the switcher bar:

```html
<nav class="nd-lang-switcher" aria-label="Language">
  <a href="https://docs.example.com/en/guide/setup/" lang="en">English</a>
  <a href="https://docs.example.com/fr/guide/setup/" lang="fr" aria-current="page">Français</a>
  <a href="https://docs.example.com/ja/guide/setup/" lang="ja">日本語</a>
</nav>
```

## Options Reference (`I18nOptions`)

| Property / Fluent Helper | Default | Purpose |
|---|---|---|
| `Enabled` / `.Disable()` | `true` | Master toggle for all i18n behavior. |
| `DefaultLocale` / `.WithDefaultLocale(code)` | `"en"` | Primary locale used for unprefixed files, `x-default`, and fallback synthesis. |
| `Locales` / `.AddLocale(code, label)` | `[("en", "English")]` | Ordered list of supported BCP-47 locales and switcher labels. |
| `FallbackToDefaultLocale` / `.WithoutFallback()` | `true` | Synthesizes missing translations from `DefaultLocale`. |
| `UntranslatedNotice` / `.WithUntranslatedNotice(md)` | `[]` | Markdown banner inserted at the top of synthesized fallback pages. |
| `EmitHreflangTags` / `.WithoutHreflang()` | `true` | Emits `<link rel="alternate" hreflang="...">` in `<head>`. |
| `EmitLanguageSwitcher` / `.WithoutLanguageSwitcher()` | `true` | Injects `.nd-lang-switcher` navigation links when >= 2 locales exist. |
| `EnrichSitemap` / `.WithoutSitemapEnrichment()` | `true` | Adds `xhtml:link` alternate tags to `sitemap.xml`. |
